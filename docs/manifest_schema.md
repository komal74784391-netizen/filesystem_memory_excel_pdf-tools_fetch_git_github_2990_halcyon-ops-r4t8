# Manifest record schema

One JSON object per line, records sorted by `candidate_id` ascending.

| field | type | source |
| --- | --- | --- |
| `candidate_id` | string | intake ticket |
| `candidate_name` | string | intake ticket |
| `program_code` | string | registry |
| `cohort_label` | string | registry |
| `delivery_mode` | string | registry |
| `exam_date` | string | registry |
| `time_slot` | string | registry |
| `room` | string | registry |
| `lead_invigilator` | string | registry |
